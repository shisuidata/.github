## We build for data work that must hold up under scrutiny.

**Shisui** (拾穗) means gathering what others overlook. We bring that idea to the space between AI agents and real data systems: preserve context, expose evidence, constrain execution, and keep people in control.

No magic black boxes. No confusing generated output with trusted results. Just open tools and practical methods for making data work more reviewable, reproducible, and useful.

## Our working principles

| | Principle | What it means |
|:--|:--|:--|
| `01` | **Constrain before execution** | An AI-generated candidate is input to a process—not permission to act. |
| `02` | **Evidence over confidence** | Important outputs should be inspectable, attributable, and reproducible. |
| `03` | **Humans stay in control** | High-impact actions need clear boundaries and deliberate approval. |
| `04` | **Methods must survive real work** | Useful systems handle ambiguity, permissions, failure, and handoff—not only demos. |
